# Security policy

## Reporting a vulnerability

If you find a security problem in Ekin, please email **security@txeksystems.com** and do not open a public issue.

Include, if you can:

- the Ekin version (it is in the window title) and your Windows version;
- what the problem is and the steps to reproduce it;
- what an attacker could do with it.

We confirm we have received your report within 5 working days and keep you informed until it is fixed. Our replies
come from hola@txeksystems.com. If you wish, we credit you in the [changelog](CHANGELOG.md) when the fix is released.

Please give us reasonable time to release a fix before you make the problem public, and do not access or change
other people's data while you investigate. There is no bug bounty.

## Supported versions

Only the latest release receives security fixes. Installed copies find new versions in this repository's
[Releases](https://github.com/Txek-Systems/ekin/releases) and update themselves.
