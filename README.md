# Ekin

Ekin is a local Kanban board for Windows that works with your AI agents (Claude Code and other command-line agents)
through MCP. Your boards stay on your computer: no account and no servers of ours.

This repository holds no source code: only the releases, this README and the [changelog](CHANGELOG.md).

## Download

Get the latest installer (`Ekin-Setup-vX.Y.Z.exe`) from [Releases](https://github.com/Txek-Systems/ekin/releases/latest).
Installed copies find new versions here, check the installer against the SHA-256 published with each release and
update themselves.

Ekin runs on 64-bit Windows. Every computer gets a 30-day free trial, with no account and no card.
